# v2 数值约定与修改范围

依据用户提供的《2026数字组考核v2》A 题第 2、3、5 页。
固定 S=8、d=4；Q/K/V 与 O 均为 8 位有符号整数。
本文仅说明本轮数值修改，不是最终设计报告或性能分析。

## 计算规则

1. `score[j] = sum(q[i]*k[j][i])`，不做 `1/sqrt(d)` 缩放。
2. 点积阶段同时维护最高分；所有 Score 算完后才进入 EXP。
   因而 EXP 使用的是全局最大值，无需单独增加 MAX 状态。
3. `distance = max_score-score[j]`，非负整数。
4. 指数表输出 UQ1.4（1 位整数 + 4 位二进制小数）：

| distance | 整数编码 | 实际权重 |
|---|---:|---:|
| 0 | 16 | 1 |
| 1 | 6 | 0.375 |
| 2 | 2 | 0.125 |
| 3 | 1 | 0.0625 |
| ≥4 | 0 | 0 |

编码为 `floor(16*exp(-distance)+0.5)`，没有先把指数取成整数。
`exp(0)=1` 必须能准确表示，所以需要一位整数位；4 位总宽无法存下编码 16。
距离 ≥4 时 `16*exp(-distance)<0.5`，其零值是上述量化规则的结果。
v2 未明确 LUT 舍入方向，本实现选择四舍五入量化，而不是截断。

5. `L=sum(weight_code)`，`ACC[i]=sum(weight_code*V[j][i])`。
   两者均保留 4 位小数；除法中缩放因子 16 抵消。
6. 最终输出为最近整数，半整数远离零。示例：0.5→1、-0.5→-1、2.5→3。
   v2 的“round/四舍五入”没有单独定义负半整数，本约定明确采用对称舍入，
   不采用 Python 内置 round 的半整数取偶数规则。
   RTL 计算 `floor((abs(ACC)+floor(L/2))/L)` 后恢复符号。
   该公式对奇数和偶数 L 均成立。Python 主模型使用整数运算，
   独立参考使用 Decimal 的 ROUND_HALF_UP；二者分别验证。

## 与本次修改相关的位宽

以下范围指寄存器里的整数编码；带 4 位小数的量除以 16 才是实际数值。

| 量 | 编码范围 | 当前位宽 |
|---|---|---|
| 单项 Q×K | -16256..16384 | signed 16 |
| Score / max_score | -65024..65536 | signed 18 |
| distance | 0..130560 | unsigned 19，保留原设计扩展减法宽度 |
| weight | 0..16 | unsigned 5，UQ1.4 |
| L | 16..128（累计过程中从 0 开始） | unsigned 8，含 4 位小数 |
| weight×V | -2048..2032 | signed 14，含 4 位小数，保留乘法全宽 |
| ACC | -16384..16256 | signed 16，含 4 位小数，留一位余量 |
| O | -128..127 | signed 8，无小数位 |

权重转成带符号乘数前补零，避免编码 16 被误解成负数；乘积累加前做符号扩展。
ACC 扩展到 36 位后取绝对值，并加 floor(L/2)。原 36 位多周期除法器保留，
本轮不优化它的宽度或阶段时序。合法输入的加权平均及其整数舍入都在 V 的整数极值之间，
输出饱和分支只是保护，不应在合法输入下掩盖溢出。

## 验证与边界

新增定向样例包含 0.375/0.5/0.625、正负半整数、int8 边界、奇数分母 L=17、
距离 3→4 的量化归零边界；这些样例同时进入 Python 测试和 RTL 测试向量。
旧的正负极值、Score 极值、随机输入、复位、停顿、连续任务测试继续保留。
错误注入新增“移除舍入偏置”，用于确认测试能识别退回截断输出的错误。

正确性以 RTL 和 v2 整数量化模型逐项一致为准；独立浮点/高精度参考用于观察量化误差。
4 位小数会舍弃低权重，某些极端输入相对浮点结果可能有明显误差，不能沿用旧 17 位小数的精度结论。
